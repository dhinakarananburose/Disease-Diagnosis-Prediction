Clinical AI System Architecture & Architecture Overview

Comprehensive breakdown of data modeling, model selection, and API deployment.

End-to-End ML Pipeline

Trained on $N=918$ observations across 5 clinical datasets (Cleveland, Hungarian, Switzerland, Long Beach, VA). Features are processed using median imputation for zero values (`chol=0`), Standard Scaling for continuous variables, and One-Hot Encoding for categoricals.

Strict Leakage Isolation

5-Fold Stratified Cross-Validation was performed exclusively on the training split ($N=734$). Imputation and scaling parameters were fitted strictly on training folds to eliminate data leakage before final model persistence.

FastAPI Inference Service

Exposes zero-latency REST endpoints for `/health`, `/predict`, and `/predict/batch` with strict Pydantic v2 schema validation. Deployed via Docker with Uvicorn worker process.

Model Architecture & Hyperparameters

Final tuned pipeline serialized as models/final_model.joblib.

Classifier Model: Support Vector Classifier (SVC)
Hyperparameters: C = 100, kernel = 'linear', probability = True, gamma = 'scale'
Preprocessing: Median Imputation + StandardScaler + OneHotEncoder
Validation Method: 5-Fold Stratified GridSearchCV

End-to-End System Architecture Pipeline

Leakage-isolated processing flow from raw feature observation to FastAPI inference prediction.

1
Clinical Input
10 raw observation features (`age`, `sex`, `cp`, `trestbps`, `chol`, `fbs`, `restecg`, `thalch`, `exang`, `oldpeak`)
↓
2
Validation
FastAPI Pydantic schema validation (`app/schemas.py`) enforcing bounds without stack trace exposure.
↓
3
Preprocessing
Median Imputation (`chol=0 -> nan`) + StandardScaler + OneHotEncoder (fitted strictly on training set `X_train`).
↓
4
Tuned SVM
Persisted Trained SVM Pipeline (`models/final_model.joblib`): `SVC(C=100, kernel="linear", probability=True)`.
↓
5
Prediction
Returns structured JSON containing `predicted_class` (0 or 1), `predicted_probability`, and `model_name`.
