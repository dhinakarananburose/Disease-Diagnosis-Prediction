Model Architecture & Hyperparameters

Final tuned pipeline serialized as models/final_model.joblib.

Classifier Model: Support Vector Classifier (SVC)
Hyperparameters: C = 100, kernel = 'linear', probability = True, gamma = 'scale'
Preprocessing: Median Imputation + StandardScaler + OneHotEncoder
Benchmarked Models: Logistic Regression, K-NN, Decision Tree, Random Forest, SVM
Validation Method: 5-Fold Stratified GridSearchCV

End-to-End System Architecture Pipeline

Leakage-isolated processing flow from raw feature observation to FastAPI inference prediction.

1
Clinical Features Input
10 raw observation features (`age`, `sex`, `cp`, `trestbps`, `chol`, `fbs`, `restecg`, `thalch`, `exang`, `oldpeak`)
↓
2
FastAPI Pydantic Validation
Strict schema validation (`app/schemas.py`) enforcing canonical bounds without raw stack trace exposure.
↓
3
Leakage-Isolated Preprocessing
Median Imputation (`chol=0 -> nan`) + StandardScaler + OneHotEncoder (fitted strictly on training set `X_train`).
↓
4
Persisted Trained SVM Pipeline
Loaded from `models/final_model.joblib`: `SVC(C=100, kernel="linear", probability=True)`.
↓
5
Prediction Response Output
Returns structured JSON containing `predicted_class` (0 or 1), `predicted_probability`, and `model_name`.
