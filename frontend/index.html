Final Model Architecture

Selected after 5-algorithm benchmark.

Selected Classifier: Tuned Support Vector Machine (`SVC`)
Optimal Hyperparameters: C = 100, kernel = 'linear', probability = True, gamma = 'scale'
Preprocessing Pipeline: Leakage-Isolated Median Imputer + StandardScaler + OneHotEncoder
Algorithms Benchmarked: Logistic Regression, K-Nearest Neighbors, Decision Tree, Random Forest, Support Vector Machine
Validation Strategy: 5-Fold Stratified GridSearchCV
