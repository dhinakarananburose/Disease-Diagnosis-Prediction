### About Section Text
A production-structured, end-to-end machine learning application built on clinical data ($N=918$). The repository encompasses exploratory data analysis, a leak-free preprocessing pipeline, baseline comparisons across 5 classification algorithms, hyperparameter-tuned Support Vector Machine (SVC), automated model persistence, a reusable inference engine (`src/predict.py`), a FastAPI REST application with Pydantic validation, 142 automated tests (`pytest`), and containerized deployment via Docker and Docker Compose.

*Disclaimer: This application is a machine-learning research prototype and is not a clinically validated diagnostic system.*
